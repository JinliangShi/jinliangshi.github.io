# Personal Homepage

一个轻量静态个人主页，风格参考极简学术主页：居中头像、姓名简介、导航、项目、文章与联系方式。

## 本地预览

直接打开 `index.html`，或在当前目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 自定义

- 在 `index.html` 中替换姓名、简介、项目、文章和链接。
- 在 `styles.css` 中调整颜色、字体、间距和头像样式。
- 如果要部署到 GitHub Pages，把这几个文件推到仓库根目录即可。
